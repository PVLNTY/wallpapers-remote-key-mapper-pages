Работает локально

Настройки остаются на устройстве. Подключение к интернету приложению не требуется.

Настройка

1. Установите APK

Откройте Remote Key Mapper в списке приложений Android TV.

2. Включите специальные возможности

Разрешите Remote Key Mapper в настройках специальных возможностей Android, чтобы приложение получало события пульта.

3. Назначьте кнопку

Выберите «Добавить кнопку», нажмите физическую кнопку на пульте и укажите приложение.

Кнопка Settings

Возможность переназначить Settings зависит от прошивки телевизора и от того, какая служба специальных возможностей первой получает событие. Если его перехватывает служба другого лаунчера, отключите её, оставив Remote Key Mapper включённым. Проверьте назначение настоящим пультом.

Приложение использует специальные возможности только для записи нажатия и запуска назначенного приложения. Разрешение на интернет ему не нужно.
